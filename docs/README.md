# Documentation Folder

Reference guides and API specifications for the Fluxenite Chat application.

## Contents

- **api.http** — HTTP request examples for testing backend endpoints (Insomnia/Postman compatible)
- **firestore-indexes.json** — Firestore composite indexes required for efficient queries
- **firestore-security-rules.md** — Security rules for Firestore database access control

## Purpose

Central location for deployment guides, API docs, and cloud configuration references. Use `api.http` to test the backend REST API and WebSocket endpoints during development.
